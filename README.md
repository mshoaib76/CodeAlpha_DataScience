# CodeAlpha Data Science Projects

This repository contains three Data Science and Machine Learning projects completed as part of the CodeAlpha Data Science Internship program.

## Projects Included

### 1. Iris Flower Classification

A machine learning classification project that predicts the species of an iris flower based on its measurements.

#### Dataset

* File: `Iris.csv`
* Features:

  * Sepal Length
  * Sepal Width
  * Petal Length
  * Petal Width
* Target:

  * Iris Species

#### Objectives

* Perform data preprocessing
* Explore dataset patterns
* Train classification models
* Evaluate model performance
* Predict flower species from input features

---

### 2. Sales Prediction

A regression-based machine learning project used to predict product sales based on advertising expenditure.

#### Dataset

* File: `Advertising.csv`

#### Features

* TV Advertising Budget
* Radio Advertising Budget
* Newspaper Advertising Budget

#### Target

* Sales

#### Objectives

* Analyze relationships between advertising channels and sales
* Build predictive models
* Evaluate prediction accuracy
* Identify the most influential advertising medium

---

### 3. Unemployment Analysis

A data analysis project focused on understanding unemployment trends.

#### Dataset

* File: `Unemployment_Rate_upto_11_2020.csv`

#### Objectives

* Clean and preprocess unemployment data
* Analyze unemployment rates across regions
* Visualize trends and patterns
* Generate insights from historical unemployment statistics

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/CodeAlpha_DataScience.git
cd CodeAlpha_DataScience
```

Install required packages:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

---

## Running the Projects

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open any of the following notebooks:

* `iris flower classification.ipynb`
* `Sales Prediction.ipynb`
* `unemployment_analysis.ipynb`
